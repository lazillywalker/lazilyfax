# LazilyFAX

LazilyFAX is a lightweight FAX sending system for Linux.

This repository provides official update information,
documentation, known issues, and support information for LazilyFAX.

## Features

- Send PDF documents by FAX
- FAX phonebook
- Transmission history
- FAX preview
- Header settings
- Multi-language support
- English and Japanese interface

## Supported Environment

LazilyFAX is currently developed and tested on Linux Mint.

A compatible USB FAX modem is required for FAX transmission.

## Current Version

Version 1.0.0

## Updates

Update information and release notes will be published in this repository.

Future updates may include additional languages and functionality.

## Support

Bug reports and known issues will be managed through this repository.

For purchaser support, please refer to the contact information included
in the LazilyFAX manual.

## Purchase

LazilyFAX will be distributed through the official sales page.

The application itself is not distributed from this public repository.
