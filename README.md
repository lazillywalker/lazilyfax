# LazilyFAX

Linux Mint向けのFAX送受信・留守番電話アプリです。
This repository contains product information, update metadata and support information.

## 機能 / Features
- PDFのFAX送信・プレビュー・ヘッダー設定
- 電話帳と送受信履歴、受信原稿の管理
- 留守番電話の案内・録音・再生、FAXへの切替
- 日本語・英語・韓国語・ドイツ語のUIとマニュアル

## 対応環境 / Environment
Linux Mint 22.x / amd64。対応USB FAXモデムと電話回線が必要です。
モデムのFAX対応と音声対応は異なります。留守電は音声対応機種で実際の案内再生・録音を確認してください。

## 公開準備中の版 / Release preparation
Debian package: 2.0.0-3。電話帳とヘッダー設定のノートPC向け表示調整を含みます。
販売公開・更新配信の開始は別途案内します。実回線・別PC初回導入等の最終確認は継続中です。

## 更新 / Updates
更新前にFAX・留守電の待受と各画面を終了し、アプリのバックアップと録音フォルダーの別保存を行ってください。
このリポジトリには販売用の完全debを掲載しません。旧試験版からの更新方法と正式版の配布先は、公開時に案内します。

## お問い合わせ / Support
購入者は購入先の問い合わせ機能をご利用ください。公開Issueへ電話番号、氏名、FAX原稿、録音、ライセンス情報を投稿しないでください。
